# 抖音真人视频封面 Skill

提供一张真人照片和一句主标题，自动补齐小标题并生成可导入剪映的封面。

- 原图：1080×1920，9:16。
- 预览：180×320，按小图检查标题与人物辨识度。
- 保留真人身份和主标题，自动安排辅助文案、配色、抠像及版式。
- 输出图片与完整生成提示词，支持后续局部修改。

![小图预览](references/approved-preview.png)

## 安装与使用

将本仓库放到 `~/.codex/skills/douyin-real-person-cover`，在支持内置图像生成工具的 Codex 中使用。

发送真人照片和主标题，例如：

> 使用 $douyin-real-person-cover 制作封面。主标题：一场婚礼只发一条成片？同一场婚礼可以拆成三条获客内容

图片生成使用宿主内置 image_gen；没有该工具的环境不能仅靠本 Skill 生成图片。示例肖像只作风格参考，新作品应使用自己的或已获授权的照片。

详细规则见 [SKILL.md](SKILL.md)。
